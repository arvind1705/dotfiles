Configs you can tweak

config.concurrency

DB connections per query queue. Raise when the database has headroom.

datasources.<name>.maxPool

Max connections per data source. Isolate hot sources as named entries.

datasources.<name>.queryTimeout

Kills runaway queries per source before they clog the queue.

config.scheduledRefreshQueriesPerAppId

Parallel pre-aggregation builds per tenant. Raise to shorten refresh lag.

redis.poolMin / poolMax

Redis queue connections (defaults 2 / 1000). Raise max under queue pressure.

config.queryLimit / queryDefaultLimit

Caps result rows. Lowers memory spikes from huge queries.

config.jobRunners (cubestore)

Parallel insert / compaction jobs. Defaults to 4.

config.queryTimeout (cubestore)

Slow-query ceiling in seconds. Defaults to 120.

When to use it?

API ×N — more cashiers for query checkout.

Scale out when queries slow down under load.

Store workers ×N — more shelves for pre-aggregations.

Scale out when refreshes lag or storage fills.

↕ Machine size — bigger truck, not more trucks.

Grow first if pods run out of memory, then add nodes.

Concurrency — more lanes on the same highway.

Raise only if the database and cache have headroom.
